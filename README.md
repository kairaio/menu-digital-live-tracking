# Menu Digital + Live Tracking Demo

Demo website untuk presentasi ke calon customer resto.

Fitur demo:
- Menu digital langsung tampil tanpa bergantung pada JavaScript untuk render awal
- Add to cart dan checkout demo
- Tracking order customer
- Driver Mode
- Multiple delivery stops
- Admin dashboard
- Simulasi pergerakan kurir

> Catatan: tracking pada demo ini masih simulasi frontend. Implementasi produksi membutuhkan GPS device driver, backend/database real-time, autentikasi, dan link tracking per order.
